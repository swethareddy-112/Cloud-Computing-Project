# ☁️ Cloud-Based Task Management System

A simple **Cloud-Based Task Management System** built using **Python** and **Google Colab**. This project demonstrates basic cloud computing concepts by allowing users to create, view, update, and delete tasks through a simple command-line interface. Task data is stored in a CSV file for easy management.

---

## 📌 Features

* ➕ Add new tasks
* 📋 View all tasks
* ✅ Mark tasks as completed
* 🗑️ Delete tasks
* 💾 Store tasks in a CSV file
* ☁️ Run directly on Google Colab

---

## 🛠️ Technologies Used

* Python 3
* Google Colab
* Pandas
* CSV File Storage

## 🚀 Getting Started

### Prerequisites

* Google Account
* Google Colab
* Basic knowledge of Python

### Steps to Run

1. Clone this repository:

```bash
git clone https://github.com/your-username/Cloud-Task-Management-System.git
```

2. Open **task_management.ipynb** in Google Colab.

3. Run the notebook.

4. Use the menu to:

   * Add tasks
   * View tasks
   * Mark tasks as completed
   * Delete tasks

---

## 📖 How It Works

The application stores tasks in a CSV file named `tasks.csv`. Users interact with the program through a simple menu-driven interface. Every change made to the task list is automatically saved to the CSV file.
